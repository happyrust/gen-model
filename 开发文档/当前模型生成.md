### 4. **模型类型分类处理**

系统根据不同的模型类型采用不同的生成策略：

1. **基本体 (PRIM)**: 
   - 直接几何计算
   - 使用 `prim_model::gen_prim_geos()`

2. **拉伸体 (LOOP)**:
   - 基于路径的拉伸算法
   - 使用 `loop_model::gen_loop_geos()`

3. **元件库 (CATA)**:
   - 标准组件实例化
   - 使用目录参数化

4. **分支吊架 (BRAN)**:
   - 层级子节点展开
   - 递归处理子组件
