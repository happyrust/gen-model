## 一、总体结论：core.dll 的几何生成是【两条路 + 一个几何内核】

```
ELMODL(逐元素建模) → GTGEOM(几何枢纽, cachegml, 0x10341d2e)
        │
        ├─(1) 现代 C++ CSG 路【首选】: sub_10714E60 "GTGM2"(0x10714e60)
        │        → CSG_TreeBuilder::getCSGTree(0x10715b30)  ← noun→builder 注册表分派
        │        → 各 family 的 getCSGTree 虚函数(见 §3)构建 CSG 树(int 句柄)+ D3_Transform
        │        成功即返回(class=4)，几何已是一棵 CSG 树
        │
        └─(2) 旧 FORTRAN 路【回退】: 按 noun 大 switch
                 ├ 目录件 → sub_10714FC0(0x10714fc0): create_geometry()+目录变换
                 └ 设计图元 → sub_10343B80(0x10343b80) "gml_bkend/CRDESI": 逐 noun 建基本体
        │
        ▼ 两条路产出的几何句柄都交给
   SGDRAW(build, sub_102556DE, 0x102556de): 迭代几何集 → 逐项套矩阵(MAT16/CONCAT) → 落图形段
        │
        ▼ 几何内核(libgm, 独立模块): gm_CreateCombination(CSG 布尔) / gm_AddMember /
          gm_CreateTransform / gm_SetTransform / gm_CreateFacetStructure(网格化→facet)
```

**GTGEOM 的真实开头**（活桥反编译坐实，纠正 GL3D「GTGEOM 是单一 FORTRAN 枢纽」的印象）：
```c
if ( unk_10E98674 == 1 || (v15 = sub_10714E60(v37,&v9,a2,a3), (v15 & 1) == 0) )
{   // 全局旗标强制旧路 或 现代 CSG 路失败 → 走旧 FORTRAN noun-switch
}
else { v11 = 4; }   // 现代 CSG 路成功：*a2=CSG树句柄, a3=变换, 直接返回
```
即：**优先走现代 C++ `CSG_TreeBuilder::getCSGTree`，失败才回退旧 FORTRAN**。97Q2 要对标的是现代路。

## 二、GTGEOM 的现代入口 sub_10714E60 "GTGM2"（0x10714e60）

C++，把设计元素喂给 CSG 树构建器：
```c
DB_Ref r(a1); DB_Element e(r);
CSG_TreeBuilder* b = CSG_TreeBuilder::instance();
if ( b->getCSGTree(e, CSG_TreeBuilderOptions::defaultPlugger, &geom, &transform) ) {
    tranToFloat12(&transform, out12);   // 变换转 12 元(3x4)浮点数组
    *a3 = geom; *a4 = out12[..]; return -1;   // 成功
}
return 0;
```
- 入口对象：`DB_Element`（e3d-io 侧的 DbElement 门面正对标它）。
- 选项：`CSG_TreeBuilderOptions::defaultPlugger`（默认属性插取器）。
- 产物：`geom`（CSG 树句柄）+ `D3_Transform`（世界/局部变换，输出为 3x4 = 12 浮点）。

### 3.3 板 PANE 生成 = 环拉伸 + CSG 挖洞（MDR_BPanelVisualisationManager::getCSGTree 0x109fff10）
```c
if (!isWanted(options, elem, &label)) return 0;
gm_SetDefaultLabel(label);
sub_10A03D40(ref, options…);           // 建面板上下文
panel = sub_10A04590(transform);       // ★建板基础实体(环拉伸, 见 3.5)
comb = 0; first = 1;
for (m = elem.firstMember(); m.isOK(); m = m.next()) {
    if (m.type() ∈ {NOUN_NBOX,NCYL,NPOLYH,NSLC,NSNO,NDIS,NCON,NPYR,NCTO,NRTO,NREV}) {  // 负几何成员
        if (first) {                        // 第一个洞：建差集
            first = 0;
            comb = gm_CreateCombination(3);          // ★op=3 = 差集(difference)
            t = gm_CreateTransform();
            gm_AddMember(panel, t, comb);            // 板作为差集第一个成员(被减数)
        }
        prim = CSG_BasicPrimitive::findPrimitive(m.hardType());
        neg  = prim->build(m);                        // 建负几何图元
        tr   = gm_CreateTransform();
        m.getAtt(ATT_TRANS, &xf);  gm_SetTransform(tr, xf);   // 读成员的 ATT_TRANS 变换
        gm_AddMember(neg, tr, comb);                 // 负几何作为差集后续成员(减数)
    }
}
return comb ? comb : panel;
```
**要点**：板本体 = 边界环拉伸；洞 = 负几何图元成员，用 `gm_CreateCombination(3)`（差集）把板做被减数、各负几何做减数逐个 `gm_AddMember`。**这就是 97Q2 该复刻的板+洞 CSG 语义。**

### 3.4 正/负图元 builder（CSG 语义的两半）
- **CSG_TreeBuilderPrimitive::getCSGTree（0x10726890）**：
  `prim = CSG_BasicPrimitive::findPrimitive(hardType); geom = prim->build(elem);`
  然后 `geom = CSG_PrimitiveUtilities::addHolesBelowPrimitive(elem, geom, options)`（**减去其下负几何子**）；
  若 owner 是 TMPL 且 TMPL 的 owner 是 FIXING → 迭代模板 `addHolesBelowTemplate`（减去固定件开孔）。
- **CSG_TreeBuilderNegativePrimitive::getCSGTree（0x10726770）**：
  `geom = prim->build(elem); v9 = CSG_PrimitiveUtilities::addStandAloneNegative(elem, geom);`
  若 owner 是 **NOUN_BPANEL** → 清空变换（负几何在板坐标系里做差）。
- 关键工具（都在 0x10）：`CSG_BasicPrimitive::findPrimitive(DB_Noun const*)` 0x107266f0（图元 builder 注册表）、
  `addHolesBelowPrimitive` 0x10726150、`addStandAloneNegative` 0x10726620。
- **CSG 语义总结**：正图元 = 自身 ⊖ 其下负几何；独立负几何 = 登记为「待被父(板/图元)减去」；板 = 环拉伸 ⊖ 负几何成员。

### 3.5 环拉伸本体 sub_10A04590（0x10a04590，板/墙共用）

**★现代分派 vs findPrimitive 的路由关系（关键结论，直接影响 97Q2 的取舍）**
- CSG_TreeBuilder plug 注册表由 `addPlug` @ `0x107158b0` 灌，共 **13 个注册站点**。其中
  `CSG_PrimitiveUtilities::initialise` 只挂：**BOX/CYLI/CONE/PYRA→CSG_TreeBuilderPrimitive**、
  **NBOX/NCYL/NCON/NPYR→CSG_TreeBuilderNegativePrimitive**、11 个 HVAC/NOZZ→CSG_TreeBuilderCat。
  其余 12 个站点是电缆桥架(CTSTRA/CTBEND…)、网格/标注(REFGLN/AIDLIN/LINDIM…，多为伪属性)、
  舾装(BNDLIN/INSURQ/FLRLAY/CLNTIL/*Fitting)、自定义 MyBox(UDET noun) 等家族——**都不挂 DISH/SNOU/CTOR/RTOR/SLCY/POLYHE/EXTR/REVO**。
- 分派器 `getCSGTree` @ `0x10715b30`：按 `actualType→type→hardType` 三查 plug map，
  **查不到就 `return 0`，没有默认兜底**。GTGEOM 收到 0 → 回退旧 FORTRAN CRDESI(§4.3)。
- ⇒ **独立(顶层)的 DISH/SNOU/CTOR/RTOR/SLCY/POLYHE/EXTR/REVO 走旧 FORTRAN 路**；
  它们的 `CSG_Basic*` builder（尤其负几何变体 NDIS/NSNO/…）主要在**板/墙的负几何成员、
  正图元的 addHolesBelowPrimitive 开孔**这些上下文里被 `findPrimitive` 直接取用——
  `primList_` 覆盖全 24 noun 就是为了「成员/开孔」这个共享图元工厂，而顶层现代路目前只认 4 正 4 负基本体。

**对 97Q2 ams1112 的补充**
1. 正几何 build 的公式就是上表：**按 noun 读固定几个具名设计属性 → 调对应 `gm_Create*`**，属性名与顺序已坐实，可直接照搬到 Rust。
2. ams1112 若只覆盖「板 + 基本体 + 负几何挖洞」，现代路的 4 基本体(BOX/CYLI/CONE/PYRA) + 负几何成员(NBOX/NCYL/NCON/NPYR + 板内 N* 系列) 已够；
   DISH/SNOU/环/斜柱/多面体/回转 等**独立**图元要么复刻旧 FORTRAN CRDESI(§4.3)，要么自行补建现代 builder。
3. EXT/POL/REV 与板本体同源（子环/顶点 → 轮廓 → 拉伸/回转，见 §3.5 与 `sub_1071C0E0/DCF0/C4F0`），不是标量图元。

#### 3.7.1 轮廓装配核心 `sub_10719900`（loop → D2_Profile，EXT+REV 共用）@0x10719900

这是「轮廓/顶点如何组装」的答案本体。签名 `D2_Profile* sub_10719900(D2_Profile* out)`：


## 六、对 97Q2 ams1112 算法的直接建议

1. **主线对标现代 CSG 路**，不是旧 FORTRAN：每 noun 一个 builder（Panel/Wall/Primitive/NegativePrimitive/Cat），
   统一签名 `getCSGTree(DbElement, options) → (CSG树, 变换)`。这正好架在 e3d-io 的 DbElement 门面上。
2. **板 PANE**：`环(PLOO→PAVE 顶点) → 2D 多边形 → 按厚度拉伸 → 3D 实体`，再对负几何成员做 `difference`。
   Rust：loop→`geo::Polygon`→extrude(厚度)→manifold；洞= N* 图元 manifold `-` 运算。
3. **负几何统一按 CSG 差集**：`gm_CreateCombination(3)` = 被减数(板/正图元) ⊖ 各减数(N* 图元，各带 ATT_TRANS 变换)。
4. **正图元还要减「其下负几何子 + FIXING/TMPL 开孔」**（addHolesBelowPrimitive/Template）——别漏了模板开孔。
5. **变换**：成员几何各自 `gm_SetTransform`（读 ATT_TRANS/ORI/POS），父子 `CONCAT` 级联；最终 12 元(3x4)。
6. **基本体尺寸**从设计属性 `DGETR` 直读（圆柱=直径→半径+高；盒=半尺寸；snout=7 参；斜柱带角度归一）——见 §4.3 表。
