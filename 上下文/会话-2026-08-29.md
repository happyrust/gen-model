## ida-bridge 关键信息（来自 README 调研）

- 功能：让 AI Agent 通过 CLI 对活动 IDA 数据库执行 IDAPython 和 SQL 查询；支持 UI 插件模式和 headless idalib 模式。
- 官方前置要求：IDA >= 9.0、**macOS**（本机是 Windows，需要手动适配，不能用 ida-setup）。
- 官方安装步骤（macOS）：
  1. `git clone` 仓库
  2. `uv tool install -e .` — 安装 CLI（全局）
  3. `ida-setup plugin install -e .` — 装插件到 IDA 的 Python venv（macOS 专用工具，Windows 需手动）
  4. `pi install .` + `pi install ida-docs` — 安装 agent skills
- 手动 skills 安装（README 明示）：
  - **codex / pi**: 符号链接 `skills/ida-bridge` → `~/.agents/skills/`
  - claude code: → `~/.claude/skills/`
  - Cursor 官方未提及，需要自行适配（计划：全局 `~/.cursor` 规则/skills + 本项目 `.cursor/rules`）
- 插件手动安装：`ida_bridge_plugin.py` 链接到 IDA 插件目录；`ida_bridge` 包安装进 IDA 用的 Python 环境（idapyswitch 决定）。
- 验证方式：`ida-bridge server status`（应显示 server not running）；IDA 内 `import ida_bridge`；IDA 输出窗口有 `[ida-bridge]` 日志行。
- 配套仓库 [ida-docs](https://github.com/cellebrite-labs/ida-docs)：提供 IDA 9.x API 文档 skill，官方强烈建议一起装。

## Windows 适配分析（源码审查结论）

- `src/ida_bridge/logs.py`：日志目录默认 `~/Library/Logs/ida-bridge`（macOS 路径）→ 用环境变量 `IDA_BRIDGE_LOG_DIR` 覆盖为 `%LOCALAPPDATA%\ida-bridge\logs`
- `src/ida_bridge/supervisor/commands.py`：
  - `start-ui` 硬编码 `sys.platform != "darwin"` 直接拒绝 → **Windows 限制**：不能用 CLI 启动 UI IDA，需手动启动 `ida.exe`（插件会自动连 bridge），或只用 headless
  - `start-idalib` 默认 Python `~/.idapro/venv/bin/python3` 在 Windows 不存在 → 每次传 `--python <系统python>`，已写进适配文档
  - `subprocess start_new_session=True` 在 Windows 被忽略（无害）；`_bind_log_to_pid` 的 rename 失败有 OSError 兜底（无害）
- `pyproject.toml`：requires-python `>=3.12` ✓（本机 3.12.10）；依赖 apsw/pydantic/websocket-client/websockets 全是跨平台纯轮子
- CLI 入口：`ida-bridge = ida_bridge.cli:main_cli`；插件文件 `src/ida_bridge/ida_bridge_plugin.py`
- **关键决定（单 Python 策略）**：IDA UI 通过注册表 `Python3TargetDLL` 已指向系统 Python 3.12 → 不建 venv，把 `ida_bridge`（editable）+ `idapro`（idalib）都装进系统 Python312，UI 和 headless 共用，最简且稳
