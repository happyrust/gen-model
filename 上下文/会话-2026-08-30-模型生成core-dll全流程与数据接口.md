## 关键结论：的是【两个】映像，别混

| 映像 | IDA db | image base | 内容 | FORTRAN 模块前缀 |
|---|---|---|---|---|
| **Core3D**（模型生成/绘图管线） | `core3d-retrace` | `0x10xxxxxx`（延伸到 `0x108xxxxx+`） | 元素→几何→图元→图段→视图 整条**模型生成管线** + C++ 适配器(BasLinkedBase/DB_BaseAttPlugger/CSG_BaseCSGTree/DBE_Base) | `add/` `build/` `updview/` `maplib/` `css/` `cachegml/` `replib/` `change/` |
| **core.dll**（dabacon DB 核心） | 另一 db | `0x5xxxxxx` | 数据库读取：设计库/目录库/属性/noun 分类/FORTRAN 运行时 + C++ `DB_Attribute`(`0x58ce…`)/`DB_Element` | `catdblib/` `desdblib/` `getattlib/` `exprlib/` `pplib/` `ppointlib/` `dbreflib/` `idlib/` |
| **libgm**（几何内核 kernel） | — | — | ★真正的几何构建：CSG 布尔、facet 网格化、变换、迭代器（C++ `gm_*`） | `gm_CreateCombination` `gm_CreateFacetStructure` `gm_AddMember` `gm_SetTransform` … |

> **模块边界已用 import 证据坐实**（`_imports_core3d-retrace.json`）：`0x10xxxxxx` 映像**导入自**
> `core.dll`（4859 处）+ **`libgm`**（几何内核）+ `libfl`（free-list 堆）→ 它是**独立模块**，
> 不是 core.dll 的一段。所以 `0x108xxxxx` 的 `DBE_Base::evaluate` 落在**这个 0x10 模型生成模块**里
> （与 ELMODL/BasLinkedBase 同簇），不是 core.dll(0x5) 的 DB_Attribute 簇——之前「0x5–0xE 巨物」上界估错。
>
> **★关键新发现：几何是 `libgm` 建的。** `GM*` 前缀（GMCFST/GMDRAW/GMRTRE/GTGEOM）= **G**eometry
> **M**odeller = libgm 的 FORTRAN 门面。libgm 导出 C++：`gm_CreateNormalisedItem` / `gm_CreateCombination(GM_Operation)`（**CSG 布尔**）/ `gm_AddMember` / `gm_CreateFacetStructure`（**网格化→facet**）/ `gm_CreateTransform`·`gm_SetTransform` / `gm_QueryXRay`（射线）/ `gm_CreateIterator`。
> → 对应 Rust `src/fast_model/libgm_discretise.rs` + `manifold_*`；根目录 `.scratch_libgm210.json`/`.scratch_libgm31.json` 是 libgm 存量。
>
> 用户口径「core.dll 模型生成全流程」= **Core3D(0x10) 管线**，它调 **core.dll(0x5)** 读数据、调 **libgm** 建几何。

## 一、模型生成全流程（Core3D 管线，自顶向下）

### 骨架一图流

```
设计库根元素（SITE/ZONE/EQUI/PIPE/…）
  │
  ▼ add/ADDDES (sub_1021D005)  ← 遍历入口：DB 树 DFS，逐元素挂图段
  │    · DSAVE/DGOTO/DGETI 定位+读 noun
  │    · DBEFOR→DFIND…DRETUR 迭代子女；LISTOP(列表) vs LPRMTV(图元) 分流
  │    · 图元 → css/SEGCRE 建图形段；调 change/EVALST 求值
  │
  ▼ build/MODCMP (sub_10251012)  ← 单元素「模型编译」
  │    · DGETI 读元素类型码；I*COM 谓词大 switch → 类别 v7（dword_10FCA060..074）
  │    · 定绘制模式 v8（1/2/3）
  │
  ▼ build/ELMODL (sub_1025277E)  ← 单元素建模主函数（0x1dfb，最大）
  │    ├─ 读全局表示旗标 dword_10EB4000/4004/400C（表示级/可见性/遮蔽）
  │    ├─ build/DRAWOP (sub_10254579)：按类别取旗标 → 设颜色/线型/可见/线宽（GL 属性）
  │    ├─ 遮蔽/LOD：DGETF/DGTERR/NULREF/DGETIA 读表示级 → v10 高低字 = 遮蔽 12/25/50/75/87%
  │    ├─ cachegml/GTGEOM (GTGEOM@0x10341d2e)：★取几何★ → 几何句柄 v86 + 变换 v132
  │    │      （评估目录 GML/图元定义；GTTUBG 取管件几何；GTCLEL/GTCLSH 取目录元素/形状）
  │    │      → 内部调 libgm 内核：gm_CreateNormalisedItem / gm_CreateCombination(CSG 布尔) / gm_CreateFacetStructure(网格化)
  │    ├─ 变换：ATNLOG/ATNINT 读朝向属性 → MAT16 组 4×4 → GLGOTO/GLSMAT 定位置矩阵
  │    ├─ sub_102548E1 (build/LNEGIT)：迭代**负几何**子项（NXTITM 循环）做扣减判定
  │    ├─ sub_102556DE / build/GMDRAW(sub_10254B01) / GMDRXG(sub_10254D61)：
  │    │      GMCFST 取几何首项 → sub_10527500 把图元**落入图形段**（真正"画"）
  │    │      build/SGHDRW(sub_10255013)：迭代几何子项、逐项套矩阵递归绘制
  │    └─ GMRTRE(v86)：释放几何句柄
  │
  ▼ updview/UVIEW (sub_101B2254, 0x31ec)  ← 视图级重建/刷新：把图段送显示
  │    （DESUPV/DESUPE/DESUPZ 设计视图更新；UVINIT 初始化）
  │
  ▼ change/UPGRPH (sub_1022EAEE)  ← 变更传播（增量）：只重建脏元素的图段
       （UPDATD 更新数据、EVALST 求值状态；配合 maplib MAPINS/MAPELE 维护元素↔图段映射）
```

### 各模块职责（`_core3d_funcs.json` 路由表）

| 模块 | 关键 FORTRAN 例程 | 职责 |
|---|---|---|
| **add/** | ADDELE ADDDES ADDSIT LADALL LADITM LADDED ADDREM DRWADD | 把设计元素（及其子树）加入绘图；DB 树遍历入口 |
| **build/** | **ELMODL**(建模主) **MODCMP**(编译) DRAWOP(设属性) GMDRAW/GMDRXG(画几何) NXTITM(下一项) LEVGET/LEVSET(LOD 级) GTGMRF(取几何参考) | 单元素几何构建的核心 |
| **cachegml/** | **GTGEOM**(取几何) GTTUBG(取管件) GTCLEL/GTCLSH(取目录元素/形状) | 目录 GML 几何评估 + 缓存 |
| **replib/** | DRAPRM(画图元) WDBOX(盒) WDCYLI(柱) WDSNOU(锥台) DRALIN(线) | 基本图元 → 表示（representation）库 |
| **css/** | SEGCRE SEGOPN SEGNEW SEGREP CSSNEW CSSINI STRCRE | 图形段存储（graphics **c**ommon **s**egment **s**tore） |
| **maplib/** | MAPINS MAPELE MAPGET MAPBOX MAPINI | 元素↔图段映射、包围盒（增量定位用） |
| **updview/** | UVIEW(0x31ec) DESUPV/E/Z UVINIT DESVEW | 视图更新/重画 |
| **change/** | UPGRPH UPDATD EVALST | 变更传播、增量重建 |

### 证据（决定性代码点）

- **MODCMP 的 noun 分类 switch**（`_3d_10251012.c`）：`DGETI` 读类型码 v6，然后
  `IHVCOM/IPCOMP/IHCOMP/IFCOMP/IPFCOM/IASLCO/ICABCO/IGMCOM/INGCOM/IPLCOM/IG2COM/IFICOM/IJOCOM/IPRCOM/ICOCOM/INCOMP`
  逐个判，选类别常量 `dword_10FCA060/064/068/06C/070/074`。→ **类别决定后续走哪条几何路径**。
- **ELMODL 的取几何**（`_3d_1025277e.c` L455）：`v87 = GTGEOM(&v86, &v132)`，`v87>0` 才继续；
  之后 `sub_102556DE`（提交图元）多处调用、`GMRTRE(&v86)` 收尾。→ **GTGEOM 是"生成几何"的单一枢纽**。
- **ADDDES 的树遍历**（`_3d_1021d005.c`）：`DBEFOR`→`while(!DGTERR){DFIND…}`→`DRETUR`，
  对 `LPRMTV`（图元）建段 `css/SEGCRE(sub_10232C9D)`，`LISTOP`（列表）走 `change/EVALST(sub_1022E0A7)`。
  途中 `GATSTR` 读串属性（名字/spec）、`ATNINT/ATNLOG` 读位姿属性、`sub_1021E007` 处理 pos/dir。
- **负几何**：`build/LNEGIT(sub_102548E1)` + `INGCOM` 谓词 + `NXTITM` 迭代子项 → CSG 扣减语义。
- **GMDRAW 跳过表**（`_3d_10254b01.c`）：noun `621502/621505/312510241/312510247/312510290` 直接跳过
  （非 3D / 特殊处理）；非 3D 时打 `MTRINT("GMDRAW: Skipping non-3d:")`。

## 二、数据接口清单（Core3D 管线 → core.dll / dabacon DB）

模型生成向 DB 索取数据，全部经这批 FORTRAN 例程（F 前缀=逻辑函数返回 bool；语义据命名 + 调用上下文推定）。

### A. DB 游标 / 树遍历（dabacon）
| 例程 | 签名（观测） | 作用 |
|---|---|---|
| `DSAVE(&save)` | 存 | 保存当前 DB 游标位置 |
| `DGOTO(refptr)` | 定位 | 跳到指定元素（by ref/refno） |
| `DRESTO(&save)` | 还原 | 恢复保存的游标 |
| `DBEFOR()` | 定位 | 移到首个成员之前（开始迭代子女） |
| `DFIND(spec,&err)` | 前进 | 找/前进到下一个匹配成员 |
| `DRETUR()` | 出栈 | 返回上层（子树迭代结束） |
| `DGTERR(&err)` / `DCLERR(&err)` | 状态 | 取/清 DB 错误码（10=到尾） |

### B. 属性读取
| 例程 | 作用 |
|---|---|
| `DGETI(attr,&out)` | 读整型属性（**noun 类型码**、枚举） |
| `DGETF(attr,&out)` | 读引用/field 型属性（DB ref） |
| `DGETIA(attr,arr,&n)` | 读整型数组属性（如表示级区间） |
| `ATNINT(refptr,attr,&out,&err)` | 读**具名整型**属性（间接：读 refptr 元素的属性） |
| `ATNLOG(refptr,attr,&out,&err)` | 读**具名逻辑**属性（bool） |
| `GATSTR(refptr,…,&buf,len,…)` | 读字符串属性（名字 / spec ref 文本） |
| `NULREF(&ref)` / `NULIFY(&x)` / `FCOPY(dst,src)` | 判空引用 / 置空 / 拷贝 |
| `MRSREF/MRSNCH` | 消息/引用解析 |

### C. noun 分类谓词（决定几何路径；I*=逻辑判定）
| 例程 | 推定含义 | 置信 |
|---|---|---|
| `IGMCOM` | 是几何模型（图元）组件 → 走 GTGEOM | 高（gate 几何路径） |
| `INGCOM` | 是**负**几何组件 → CSG 扣减 | 高（配 LNEGIT/负处理） |
| `IPCOMP` | 是管件组件 | 高（管件遮蔽重算循环） |
| `IHCOMP` `IHVCOM` | 是 HVAC/通风组件 | 高（同循环） |
| `IFCOMP` `IPFCOM` `IASLCO` | 是接头 / 管接头 / ASL 组件 | 中 |
| `ICABCO` | 是电缆组件（用 dword_10EB400C 旗标） | 中高 |
| `IPLCOM` `IG2COM` `IFICOM` `IJOCOM` `IPRCOM` `ICOCOM` `IECOMP` `IHLCOM` `INCOMP` | 板/二阶几何/固定件/接头/型材/连接/设备/洞孔/数值 组件 | 中（据命名） |
| `LISTOP` | 是列表/owner 型元素 | 高（ADDDES 分流） |
| `LPRMTV` | 是图元元素 | 高（建段判据） |
| `HTCOMP` `HQTYPE` `CGTCT2` | 有类型 / 取 noun 类型 / 取目录 ref | 中 |

### D. 几何构建 / 缓存（cachegml + build + replib，FORTRAN 门面）
| 例程 | 作用 |
|---|---|
| `GTGEOM(&geo,&mat)` | **建/取当前元素几何**（评估目录 GML → 几何集），核心枢纽；内部走 libgm |
| `GTTUBG` | 取管件（tubing）几何 |
| `GTCLEL` / `GTCLSH` | 取目录元素 / 目录形状 |
| `GMCFST(geo)` | 取几何集首项（GM=Geometry Modeller=libgm） |
| `NXTITM(geo,&it)` | 取几何集下一项（`sub_10402210/220/250` = 首/next/取值） |
| `GMRTRE(&geo)` | 释放几何句柄 |
| `WDBOX/WDCYLI/WDSNOU/DRALIN/DRAPRM`(replib) | 写基本图元（盒/柱/锥台/线/通用） |

### D′. libgm 几何内核（C++ `gm_*`，被 0x10 模块 import；GM*/GTGEOM 的真身）
| 例程 | 作用 | Rust 对应 |
|---|---|---|
| `gm_CreateNormalisedItem(uint)` | 建标准化几何项 | `mesh_primitives.rs` |
| `gm_CreateCombination(GM_Operation)` + `gm_AddMember(a,b,c)` | **CSG 组合/布尔**（并/交/差）| `manifold_bool.rs`/`manifold_csg.rs` |
| `gm_CreateFacetStructure(uint)` | **网格化 → facet 结构**（三角面）| `manifold_tessellate.rs`/`libgm_discretise.rs` |
| `gm_CreateTransform` / `gm_SetTransform(D3_Transform)` | 建/设变换 | glam `DMat4` |
| `gm_QueryXRay(…D3_Point,D3_Vector…)` | 射线/遮挡查询 | 拾取/空间 |
| `gm_CreateIterator(uint)` | 几何项迭代 | 遍历 facet/成员 |

### E. 图形段存储（css）+ GL 状态
| 例程 | 作用 |
|---|---|
| `GLGSEG(name,&seg)` | 取图段 |
| `GLSATT(attr,val)` | 设图段属性（颜色/线型） |
| `GLSMAT(&mat16)` | 设图段矩阵（变换） |
| `GLGOTO(&seg)` / `GLXIST(&seg)` / `GLOWNR()` | 进入 / 是否存在 / 设 owner |
| `SEGCRE/SEGOPN/SEGNEW/SEGREP`(css) | 建/开/新/替 图段 |
| `CSSNEW/CSSINI/STRCRE` | 段存储 创建/初始化/结构 |

### F. 矩阵 / 几何数学
| 例程 | 作用 |
|---|---|
| `MAT16(&out16,&mat,&vec)` | 组 4×4（旋转矩阵 + 平移） |
| `MUNIT(&m)` / `VUNIT(&v,…)` | 单位矩阵 / 单位向量 |
| `CONCAT(&out,&a,&b)` | 变换级联 |
| `GETRAM` | 取 RAM/矩阵 |

### G. 表示级 / 遮蔽（LOD）全局旗标
- `dword_10EB4000 / 4004 / 4008 / 400C / 4010`：按类别（几何/管件/HVAC/电缆/型材）的**表示 & 可见性位**；
  ELMODL/DRAWOP 从对应旗标解位 → 遮蔽百分比（12/25/50/75/87）、可见/隐藏/线宽/线型。
- `build/LEVGET`(sub_1025BC2E) / `LEVSET`(sub_1025BBC8)：取/设当前绘图 LOD 级。
