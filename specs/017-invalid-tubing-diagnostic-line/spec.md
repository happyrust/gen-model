# Spec 017：不可成管直段的诊断线型

**Created**: 2026-08-20  
**Status**: In Progress  
**Input**: 修复相邻构件之间方向不共线时直段被静默丢弃、查看端只剩一段空白的问题。E3D 对同样的连接画点线，我们必须给出等价的诊断表达。

## User Scenarios & Testing

### User Story 1 - 不可成管的直段仍然可见（Priority: P1）

作为模型查看者，我希望当两个相邻构件的连接点无法用一段直管连起来时，仍能在三维里看到一条诊断线型，而不是一段什么都没有的空白，从而立刻知道这里的连接是坏的而不是漏画的。

**Independent Test**: 取一支中间构件被删除、首尾方向不再共线的 BRAN，重生成后核对该连接仍产出一条直段记录，且被标记为不可成管。

**Acceptance Scenarios**:

1. **Given** 相邻两构件的间距大于连接容差且离开/到达方向与实际连线不共线，**When** BRAN 重生成成功，**Then** 该连接产出一条标记为不可成管的直段记录，其世界变换沿实际连线、长度等于两点间距。
2. **Given** 同一支 BRAN 上既有可成管也有不可成管的连接，**When** 重生成成功，**Then** 两类记录同时存在且各自的标记互不污染。
3. **Given** 某连接原本不可成管，**When** 模型改回共线并重生成，**Then** 该连接的记录变为可成管，不残留上一版标记。

### User Story 2 - 查看端按诊断线型显示（Priority: P1）

作为查看端，我希望不可成管的直段以既有的诊断线型（虚线中心线）呈现，与端点已删除造成的坏连接使用同一种表达，无需为新原因增加第二套渲染路径。

**Independent Test**: 对同一批直段记录，分别构造「方向不共线」「端点已删除」「两者都成立」三种输入，断言查询层给出的诊断标记一致为真。

**Acceptance Scenarios**:

1. **Given** 一条被标记为不可成管的直段，**When** 查看端拉取该 BRAN 的直段，**Then** 该段的诊断标记为真。
2. **Given** 一条未标记但端点已删除的直段，**When** 查看端拉取，**Then** 诊断标记仍为真，既有行为不回退。
3. **Given** 库中旧版本记录没有该标记字段，**When** 查看端拉取，**Then** 按可成管处理，不报错、不崩溃。

### Edge Cases

- 间距小于连接容差：仍按建模余量处理，不产出任何记录。
- 口径未知导致无法确定管径：不得因为缺少口径就把一段坏连接吞掉。
- 同一支 BRAN 全部连接都不可成管：全部记录都带标记，集合不为空。
- 不可成管的直段不得被当作实体钢体参与空间归属统计。

## Requirements

### Functional Requirements

- **FR-001**: 间距超过连接容差的相邻连接，系统 MUST 产出一条直段记录，无论方向是否共线。
- **FR-002**: 方向判定失败的直段 MUST 携带明确的不可成管标记与原因，禁止只在调试输出里提示。
- **FR-003**: 不可成管直段的世界变换 MUST 沿实际连线定向、长度等于两连接点的间距，使诊断线型正好落在两点之间。
- **FR-004**: 不可成管直段 MUST 与可成管直段走同一次分支原子替换，遵守 Spec 016 的完整集合语义。
- **FR-005**: 查询层给出的诊断标记 MUST 是「记录自带标记」与「端点已删除」的并集。
- **FR-006**: 缺少标记字段的历史记录 MUST 按可成管处理，不得导致反序列化失败。
- **FR-007**: 空间归属与实体统计 MUST 排除不可成管直段。
- **FR-008**: 回归测试 MUST 在恢复「方向判定失败即丢弃」的旧写法后失败。

### Key Entities

- **直段记录**：一条隐含直管段的关系行，新增「不可成管」标记与原因。
- **不可成管原因**：方向不共线 / 口径未知，二选一，便于后续可观察化。
- **诊断线型**：查看端既有的虚线中心线表达，本特性只扩大它的触发条件。

## Success Criteria

- **SC-001**: 指定 BRAN 重生成后，直段记录数等于间距超容差的连接数，一条不少。
- **SC-002**: 现场那两段拐死的连接 100% 带上不可成管标记，四段正常连接 100% 不带。
- **SC-003**: 不可成管直段的世界变换端点与两个连接点的偏差在连接容差以内。
- **SC-004**: 历史记录缺字段时查询层解析成功率 100%。

## Assumptions

- 直段关系表是无模式表，新增标记字段不需要迁移。
- 查看端已有虚线中心线渲染与选中材质，本特性不新增渲染路径。
- 沿用 Spec 016 的分支原子替换，不新增模型版本表。
