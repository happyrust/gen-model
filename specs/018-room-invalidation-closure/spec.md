# Spec 018：房间增量失效闭环

## 目标

保证房间归属对同 AABB 的有效几何变化、`project_hd` 中间容器搬迁及结构枚举故障均有
确定、可恢复且可观察的收敛路径。

## 需求

1. 定向生成和位姿更新必须按有效最终几何变化触发房间重算，不能只比较 AABB。
2. 暂存窗口的房间目标必须在 journal 写回前进入恢复检查点，并与水位原子提交。
3. 直写定向更新的房间任务与恢复 epoch 必须和指针写入原子提交。
4. `project_hd` 的 `CWALL/CFLOOR` OWNER 变化必须重算其直接 PANE 子元素。
5. 结构枚举失败不得丢弃其他有效工作；必须持久标记需要全量房间重建。
6. 旧计划和旧 `room_build:main` 记录缺少新增字段时保持向后兼容。
7. `/health` 读取房间重建要求必须有硬超时；持久层繁忙时返回降级状态，不阻塞整个
   健康接口。

## 成功标准

- 同 AABB 网格/布尔/对称位姿变化均产生正确且去重的房间任务与 epoch 痕迹。
- 中间容器搬迁后的 `room_panel_relate`、`room_relate.room_num` 与最终 OWNER 拓扑一致。
- 枚举故障窗口可提交，重建标记常驻；重建失败不清标记，成功后清除。
