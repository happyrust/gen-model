# Spec 014：有界暂存写回

## 目标

复制或批量增加节点产生的大 journal 必须持续显示真实写回进展；单个持久查询卡住时，
任务必须有界失败且不得推进 `applied_sesno`。

## 验收

- 普通 journal 按条数、字节数、预计行数三个上限中最先命中的维度切块。
- 显式事务保持完整并独占一块。
- 完成每块都会刷新 `commit` 阶段进展；等待心跳不算进展。
- 单查询 120 秒静默形成包含块、尺寸和指纹的错误。
- 任一块或尾事务失败时水位不推进；同窗口可幂等重放。
- `8000 / 239..=239` 最终成功，控制台显示多块进展，水位从 238 到 239。
