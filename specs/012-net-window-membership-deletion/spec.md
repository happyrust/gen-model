# Feature Specification：净窗口成员删除收口

## Requirements

- **FR-001**：父成员表从 old 移除且未在其他 OWNER 的 new 中出现的 refno 必须接受目标成员关系仲裁。
- **FR-002**：目标 OWNER 不再包含候选时，窗口必须输出候选及其不可达子树的 `Deleted`。
- **FR-003**：跨 OWNER 搬迁不得输出 `Deleted`。
- **FR-004**：成员仲裁失败必须使窗口失败且不推进水位。
- **FR-005**：同一 refno 在窗口终态最多出现一种操作，索引删除与成员删除必须去重。
- **FR-006**：补删计数必须进入口径 warning、任务结果和控制台增删改统计。
- **FR-007**：已提交窗口纠正必须使用 staging、保持水位不变并可幂等重放。

## Success Criteria

- `ams8000_0001 / 236..=236` 的净窗口和 legacy 参照臂均为 Add 0、Modified 1、Deleted 1。
- 纠正后 `pe:24384_26201` 及其关系消失，`pe:24384_26199` 保留，水位仍为 236。
- 搬迁、子树删除、解析失败和重复重放测试通过。

## Non-goals

- 不恢复生产逐会话回放。
- 不新增 SurrealDB 表或在线 REST 入口。
- 不改变 CATA 依赖闭包、监听限定和 300 秒停滞规则。
