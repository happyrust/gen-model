# 023 并行生成与收口提速规格

## 背景

初始化链路的正确性与自动化在 `docs/2026-08-17_initialization-increment-audit.md` 一轮里
已经收口，剩下的问题是慢。7999 真靶 56 MB / 120 会话基线以分钟计，`test_cal_rooms` 的房间
全量收敛单项 227 秒。

现状是「根内并行、根间串行」：`gen_model.rs` 22 处 spawn/join、`manifold_bool.rs:76` 固定
切 16 块、`occ_generate.rs` 6 处、`pdms_inst.rs` 4 处，这些 fan-out 宽度写死、不看核数，
彼此不知道对方存在。收口段的空间树重建与房间收敛则完全串行，且不在任何并发预算里。

本规格是 ADR-041 的第一个可交付：**不碰 `old-pdms-io`、不引入 ZONE 分片、不新建持久表**，
只在现有全量基线路径上把并行度收归统一管理，并把收口段的串行尾巴并行化。ZONE 分片、冻结源、
流水线重叠归 `024`。

## 要求

1. 存在**唯一**的全局几何并发闸，额度可配，默认 = 物理核数，最小 1。生成路径的所有
   fan-out（`manifold_bool`、`occ_generate`、`pdms_inst`、`gen_model` 及同类）均从该闸取额度，
   不得再出现写死的并发宽度。
2. 额度设为 1 时，行为与改动前等价：不产生新的并发形态，只是串行执行。这是本特性的回滚路径。
3. 生成期间的 journal 条目先进各自生成根的本地 buffer，根结束时整段并入窗口 journal；
   封本时按（根 ID → 表 → record id）排定稳定序。
4. ADR-038 第 2 条不被破坏：已显式声明事务的 journal 条目组保持原子、不被排序打散、
   独占一个写回块。
5. 同一份输入重复运行两次，封本后的 journal 条目序列逐条相同，`journal_digest` 与 ADR-038
   的分块边界、块指纹一致。
6. 空间树全量重建与房间全量收敛保留「全量重建」语义——输入是已落库全量数据，输出是同一棵树、
   同一批成员边——只把内部循环接入第 1 条的闸。不引入「N 次增量替代一次全量」的新路径。
7. 收口段的并行不得改变既有锁序 `STAGED_COMMIT_SERIAL → SPATIAL_STATE_SERIAL →
   GLOBAL_AABB_TREE`，换树 / 发布段仍持锁执行。
8. 并行生成下单个生成根失败记死信、不影响同批其余根封本提交；死信语义、attempts 门槛与
   显式 retry 复活路径与 `022` 保持一致。
9. 房间收敛的完成口径明确为「对**已有 mesh 的元素**全部定论」：模型死信根名下的元素暂时
   不归属任何房间，等模型补齐后由增量房间队列收敛。该口径要有回归钉子。
10. 提供改动前后的 wall-clock 对照：同一个库、同一份数据，记录总时长与分段耗时
    （解析 / 生成 / 写回 / 空间树 / 房间），并至少覆盖「额度 = 1」与「额度 = 核数」两组。

## 非目标

- 不引入 ZONE 分片、`FrozenSource`、流式拓扑索引或 scoped 解析。
- 不新建 `baseline_run` / `baseline_shard` / `baseline_root` 持久表。
- 不实现生产 / 消费 channel 的实际重叠。当前全量基线只有一个提交单元，深度 1 的 channel
  无物可叠；本轮只要求生成端与写回端的接口边界清晰到 `024` 能直接插入 channel，不要求
  跑出重叠收益。
- 不改 `data_batch_workers` 的批次级并发语义，不新增数据批次消费路径。

## 兼容性

- 额度默认值若取物理核数，则默认行为即变化；因此配置项必须在 `DbOption` 中显式存在，
  且未知值启动失败而非静默回退。
- 不改 `/api/v1/*` 既有响应形状；如需暴露闸的额度与在用量，只新增字段。
- 不改水位、队列、批次终态语义。

## 成功标准

- 额度 = 1 时全量基线结果与改动前逐表等价（`pe`、noun 属性、`ATT_UDA`、`pe_owner`、
  `inst_relate/info`、`geo_relate`、`inst_geo`、`world_trans`、`aabb`、空间树快照、
  `room_panel_relate`、`room_relate`）。
- 额度 = 核数时结果与额度 = 1 逐表等价，wall-clock 有可量化下降，且下降幅度按分段归因清楚。
- 重复运行两次的 journal 条目序列与块指纹一致，有纯函数回归测试。
- 生成路径中不再存在写死的并发宽度，有源码形状断言钉住。
- 单根死信不影响同片其余根提交，有回归测试。
- 房间收敛在存在模型死信时仍能收口，缺 mesh 的元素不归属房间且可见。

## 决策引用

- ADR-041：并行单位、全局闸、稳定序封本、收口段并行、两级发布闸门。本规格实现其第 3、4、5、
  6、7 条。
- ADR-038：写回分块上限与单查询停滞边界；第 2 条的显式事务原子性是排序约束。
- ADR-025：阶段顺序、`applied_sesno` 只承诺数据、`model_update_pending` 是唯一工作真值。
- ADR-011：单队列单派发器与 `STAGED_COMMIT_SERIAL`；本规格不触碰批次级并发。
- ADR-010 / `specs/018`：房间增量模型；本规格明确不进入该口子。
- `specs/022`：模型死信与 health 语义；本规格沿用不改。
