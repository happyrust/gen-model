# Spec 028：硬边法向分组按轮廓算，不按夹角猜

**ADR**：`docs/adr/ADR-047-hard-edges-come-from-the-profile.md`
**证据**：`docs/evidence/2026-08-24-ida-gm-collar-ruled-solid.md` §六
**前身**：specs/009 的 T040b（记了一年、一直「本期不实现」）；`d0088e93` 引入的 10° 阈值

## 问题

曲面法向该怎么分组，本仓有两套做法，**没有一套来自 E3D**：

- `src/fast_model/manifold_csg.rs`：同位置上夹角 ≤ **10°** 的面按面积加权平均
  （`SMOOTH_NORMAL_COS`）。10° 是猜的。
- `src/fast_model/sweep_mesh.rs`：侧壁逐四边形独立顶点、写面法向，等价于**全是硬边**。
  弧墙 / 斜切墙 / 环形截面因此一律渲染成折面。

E3D 的权威在轮廓上：`GM_Profile::getPolygonForFacet` 逐顶点标负号，判据是
`D2_Span::leadsSmoothlyTo`（`|1 − 点积| ≤ 1e-6`，≈0.081°）。夹角阈值与它的分歧不是
精度问题：粗弧（面片夹角 45°）在 E3D 是光顺曲面，浅折角（5.7°）在 E3D 是硬边，
一个阈值同时答这两个问题必然两头错，且错法随离散密度漂移。

## 要什么

**FR-1** 硬边由轮廓判定，逐点算出并随离散结果一起传递；判据只有一处实现，出处是
`leadsSmoothlyTo` 的 1e-6 点积。

**FR-2** 侧壁法向在软点上跨面片平均、在硬点上不平均；沿扫掠方向永远平均；端盖与侧壁
的接缝永远是硬的。

**FR-3** 分组不改拓扑：顶点数、索引、绕向、体积、包围盒一位不变，改的只有 `normals`。

**FR-4** `leadsSmoothlyTo` 的 1e-6 不得与 `isTangentDiscontinuity` 的 22.5°、`isSharp`
的 ≈48.3° 合并成一个常量。

**FR-5** 布尔之后的法向暂时仍走 10°（manifold 交回来的三角汤没有轮廓出处）。这是
**明确接受的过渡态**，必须在代码与 ADR 里写明它是近似、写明退役条件，不得默认为规则。

**FR-6** 硬边随轮廓走，**不随离散密度走**：同一副截面换一个弦高容差，硬边的位置
（在轮廓上的哪个角）不变。

## 怎样算成功

| 判据 | 怎么量 |
|---|---|
| G-1 | 环形扇区：硬边恰好是四个角，弧内部一个都不是 |
| G-2 | 整圈只剩 8 段的粗弧：侧壁法向仍等于该顶点自己的径向（逐片平直会差 1−cos22.5° ≈ 0.076） |
| G-3 | 只拐 5.7° 的直边折角：仍是硬边（10° 阈值会抹平） |
| G-4 | 同一副截面在两个差一个量级的容差下，硬边落在轮廓的同一批角上 |
| G-5 | 改动前后体积 / 顶点数 / 包围盒不变（FR-3） |
| G-6 | 三个相切判据的常量各定义一处，源码断言钉住（FR-4） |
| G-7 | Phase 2 之后：过一次布尔的构件，其未被布尔切到的曲面法向与不过布尔时一致 |

## 分期

- **Phase 1（本期）**：轮廓侧。判据 + 逐点硬边 + `sweep_mesh` 侧壁分组。门 G-1/G-2/G-3/G-5。
- **Phase 2**：布尔侧。硬边随顶点走 manifold 的属性通道，`manifold_to_plant_mesh` 改按
  属性分组。门 G-7。
- **Phase 3**：`SMOOTH_NORMAL_COS` 退役，源码断言禁止再出现夹角阈值分组。门 G-6。

## 明确不在范围内

- **`manifold_tessellate` 里那些解析原语**（柱 / 球 / 碟 / 环面）的法向：它们不是轮廓
  扫出来的，硬边由生成器自己的构造决定，是另一条线。
- **`AM_CoEdge::calcStartNormal` 的平滑组算法**（teach 0011 §8.1）：那是 E3D 出料时
  对已成形面片重新分组，与本条的「建面时就知道哪儿是硬边」不是一件事。
- **线框（`wire_vertices`）**：硬边同样是它的权威来源，但本期不动。
