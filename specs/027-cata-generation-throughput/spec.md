# 027 8000 初始化 CATA 模型生成提速规格

## 目标

在空 RocksDB 完整初始化 dbnum 8000 时，降低落盘后的 BRAN/HANG CATA 模型生成耗时，
保持模型、错误和持久身份语义不变。

## 功能要求

1. 当前分页所需子节点、命名属性、CATR、世界变换和正负体引用必须批量取得；缺失记录与
   查询失败必须可区分。
2. 同页相同 CATA 身份只解析一次，不同身份不得共享目录上下文。
3. CATA 和 Manifold 必须共用可配置的全局几何额度；额度 1 与批量读取后的串行结果等价。
4. 并发任务不得直接修改共享输出；输出、错误和摘要在任意完成顺序下保持确定。
5. 单件坏数据写入包含生成根、实例、CATA 身份、阶段和原因的 `geom_error`；数据库级失败
   使整页失败并保留重试。
6. 不使用 Legacy、内存库、OCC 或 git rev 本地依赖，不改变初始化协议和持久格式。

## 验收标准

- BRAN/HANG CATA 页归一化耗时 p50、p95 比基线至少降低 50%。
- 8000 模型生成 wall-clock 至少降低 35%，峰值内存增长不超过 25%。
- `inst_relate/info`、`geo_relate`、`inst_geo`、`world_trans`、AABB、mesh SHA-256、布尔结果
  与串行基线等价；成功根与 `geom_error` 根合并覆盖全部已调度根。
- 不以 `pending=0` 作为计时停止条件。

## 停止条件

批量读取破坏暂存上下文、并发结果不确定、错误未进入 `geom_error`、查询失败产生部分成功
回执，或性能/内存门未通过时，不启用默认并发；已验证批量读取可以保留。
