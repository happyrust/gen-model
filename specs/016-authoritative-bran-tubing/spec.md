# Spec 016：BRAN 直管关系权威替换

**Created**: 2026-08-20  
**Status**: In Progress  
**Input**: 修复管件属性变化后构件几何已更新、但 BRAN 直管段仍停留在旧连接点与旧方向的问题。

## User Scenarios & Testing

### User Story 1 - 属性变化后直管段同步更新（Priority: P1）

作为模型查看者，我希望修改 BEND 等管件的几何属性并完成增量更新后，连接该管件的直管段与新 arrive/leave 点一致，而不是继续显示第一次生成的形态。

**Independent Test**: 先生成一支含多个直管段的 BRAN，再修改中间管件的 ANGL 并重生成；核对该 BRAN 的直管关系集合、端点和世界变换全部来自第二次生成。

**Acceptance Scenarios**:

1. **Given** 一支已经生成过直管关系的 BRAN，**When** 管件属性改变并成功重生成，**Then** 旧关系集合被完整替换，新集合不存在旧端点、旧方向或多余高位索引。
2. **Given** 第二次生成的直管段数量少于第一次，**When** 重生成成功，**Then** 第一次生成独有的尾部关系不再存在。
3. **Given** 第二次生成没有任何可绘制直管段，**When** BRAN 本身生成成功，**Then** 该 BRAN 的权威直管关系集合为空。

### User Story 2 - 每条直管关系都可独立解析（Priority: P1）

作为模型客户端，我希望每条直管关系引用的世界变换与包围盒都存在，从而查询结果不会因悬空引用得到 null。

**Independent Test**: 对一次生成后的全部直管关系逐行解引用，断言世界变换与包围盒记录均存在且内容与关系生成时的数据一致。

**Acceptance Scenarios**:

1. **Given** 一次成功生成产生了直管关系，**When** 客户端解引用其世界变换和包围盒，**Then** 两类内容记录都存在。
2. **Given** 同一内容哈希已存在，**When** 重生成再次引用它，**Then** 写入保持幂等且关系仍可解析。

### User Story 3 - 删除分支时清除直管关系（Priority: P2）

作为增量维护者，我希望 BRAN 被删除或其模型子树被清理时，挂在该 BRAN 名下的直管关系一并消失，不再指向已删除构件。

**Independent Test**: 建立 BRAN 与子件及直管关系，执行现有删除清理入口，断言实例关系、直管关系和房间归属均按既有口径收口。

**Acceptance Scenarios**:

1. **Given** 被删除 BRAN 仍有直管关系，**When** DeleteCleanup 成功，**Then** 该 BRAN 的直管关系全部删除。
2. **Given** 清理或新版本写入失败，**When** 事务回滚，**Then** 旧直管关系集合保持完整，不出现半删半写。

### Edge Cases

- 直管段数量从多变少、从有变无、再从无变有。
- 多个直管段共享相同变换或包围盒内容哈希。
- 重放同一成功生成结果，终态与首次提交完全一致。
- BRAN 仍存在但属性、世界变换或连接点解析失败；旧版本必须保留，失败必须上浮。
- 直管方向不满足生成条件；不得遗留上一版相同索引的关系。

## Requirements

### Functional Requirements

- **FR-001**: 每次成功生成 BRAN 后，系统 MUST 以本次完整产物作为该 BRAN 直管关系的唯一权威集合。
- **FR-002**: 旧集合删除与新集合写入 MUST 作为一个分支原子替换提交；任一步失败不得暴露部分新版本。
- **FR-003**: 替换 MUST 覆盖“新集合更短”和“新集合为空”，不得依赖本次仍会写出的关系 id 推导删除集。
- **FR-004**: 每条新直管关系引用的世界变换和包围盒内容 MUST 在同一原子替换中持久化。
- **FR-005**: 同一替换在暂存写回重放和直接写路径上 MUST 幂等收敛到相同终态。
- **FR-006**: 已确认删除的 BRAN 或其删除子树 MUST 清除挂在该 BRAN 名下的直管关系。
- **FR-007**: BRAN 仍存在但生成失败时 MUST 保留完整旧版本并向调用方报告失败。
- **FR-008**: 回归测试 MUST 在移除“先清旧集合”或“写入世界变换/包围盒内容”任一行为后失败。
- **FR-009**: 模型生成改动 MUST 具有 live 验证记录，并同步更新唯一 live 台账。

### Key Entities

- **BRAN 直管关系集合**：一个 BRAN 当前全部隐含直管段的权威关系集合，包含确定性索引、leave/arrive、几何、世界变换、包围盒与 bore 信息。
- **世界变换内容**：由直管段变换内容寻址的共享记录。
- **包围盒内容**：由直管段世界包围盒内容寻址的共享记录。
- **分支原子替换**：见 `CONTEXT.md`；旧集合与新集合只允许完整切换。

## Success Criteria

- **SC-001**: “多段 → 少段”回归中，提交后关系数与第二次生成数完全一致，旧高位索引为 0 行。
- **SC-002**: 新集合全部关系的世界变换和包围盒解引用成功率为 100%。
- **SC-003**: 同一替换连续执行两次，关系集合及内容记录终态不变。
- **SC-004**: 替换事务注入失败时，旧关系集合保持 100% 完整。
- **SC-005**: 指定 BRAN 的现场 ANGL 增量复测后，直管关系不再包含修改前端点或已删除构件引用。

## Assumptions

- 延续 ADR-014 的分支原子替换，不新增模型版本表。
- 延续 ADR-017 的暂存路由与 ReplaySafe 约束；稳态窗口的更大提交边界不改变本特性的分支内部权威语义。
- 世界变换和包围盒继续使用内容寻址，写入路径不做单边垃圾回收。
