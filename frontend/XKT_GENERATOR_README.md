# XKT 生成器前端功能

## ✅ 功能完成

成功在前端应用中添加了 XKT 生成器功能，用户可以通过 Web 界面生成和下载 XKT 格式的 3D 模型文件。

## 🚀 访问方式

1. **启动后端服务**（已在端口 8080 运行）
   ```bash
   cargo run --features="web_ui" --bin web_ui
   ```

2. **启动前端应用**（已在端口 3001 运行）
   ```bash
   cd frontend/v0-aios-database-management
   pnpm dev
   ```

3. **访问应用**
   - 打开浏览器访问: http://localhost:3001
   - 点击侧边栏"工具"部分的"XKT生成器"

## 🎯 功能特性

### 1. XKT 生成
- **数据库号输入**: 必填项，指定要生成的数据库编号（如 1112）
- **参考号输入**: 可选项，可指定特定区域或组件（如 17496/266203）
- **压缩选项**: 可选择是否压缩，压缩后文件大小减少约 75%

### 2. 生成历史
- 查看所有生成的 XKT 文件记录
- 显示文件名、大小、时间戳等信息
- 支持查看和下载生成的文件

### 3. 用户界面
- 清晰的表单界面，易于操作
- 实时状态反馈（生成中、成功、失败）
- Toast 通知提示操作结果
- 响应式设计，适配不同屏幕

## 🔧 技术实现

### API 集成
- 调用后端 `/api/xkt/generate` 生成 XKT 文件
- 通过 `/api/xkt/download/{filename}` 下载文件
- 支持压缩和非压缩两种格式

### 状态管理
- 使用 React Hooks 管理组件状态
- 实时更新生成历史列表
- 错误处理和用户反馈

### UI 组件
- 基于 Radix UI 和 Tailwind CSS
- 自定义主题支持（亮色/暗色模式）
- 可重用的 UI 组件库

## 📋 使用步骤

1. **选择数据库**
   - 输入数据库号（例如：1112）

2. **可选参数**
   - 输入参考号指定特定区域（可选）
   - 选择是否启用压缩

3. **生成文件**
   - 点击"生成XKT文件"按钮
   - 等待生成完成

4. **下载使用**
   - 在历史记录中查看生成的文件
   - 点击下载按钮保存到本地
   - 可以在 3D 查看器中加载显示
