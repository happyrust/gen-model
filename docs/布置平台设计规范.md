# 布置平台 · 设计规范（Engineering Console）

> 由 `/impeccable`（product / 工具类界面 register）产出。目标：让这套三维评审工具「隐入任务」，去掉 AI 味，达到 Linear / Figma / Navisworks 级别的可信度与克制。
>
> 配套产物：
> - 效果图：`assets/buzhi-redesign-dark.png`、`assets/buzhi-redesign-light.png`
> - 代码令牌：`src/gui/theme_engineering_console.rs`（gpui-component）
> - 跨端令牌：`assets/design-tokens/engineering-console.css`、`engineering-console.tokens.json`

## 0. 设计原则（先立后用）

1. **中性色分五层建立 elevation**：底 → 面板 → 头部 → 悬浮 → 分割线。眼睛靠明度差找重点，而非靠边框堆叠。
2. **3D 画布是舞台**：画布压到全局最深，与机架拉开明度差；模型几何色因此更清楚，视口自然成为视觉主角。
3. **单一强调色**：工程蓝只用于「选中 / 主操作 / 焦点 / 激活」，绝不做装饰。
4. **语义色只表状态**：成功 / 警告 / 危险 / 信息四色只出现在状态语境（校审结论、日志级别、同步状态）。
5. **earned familiarity（借用标准范式）**：顶栏+侧栏+页签+命令面板+状态栏，都用行业既有心智模型，不为「新奇」自造控件。
6. **密而可读**：工具类界面允许高信息密度，但正文对比度不妥协（见 §9）。

## 2. 排版（Typography）

工具类界面用**单一无衬线**承载标题/正文/标签/数据；数据、坐标、日志、时间戳用**等宽**对齐。字号**固定 rem 梯度**（不用 fluid clamp）。

- `--font-sans`: `"Microsoft YaHei UI", "Segoe UI", "PingFang SC", "Inter", system-ui, sans-serif`
- `--font-mono`: `"Cascadia Code", "JetBrains Mono", "Consolas", ui-monospace, monospace`

| Token | 字号 | 用途 | 行高 |
|---|---|---|---|
| `fs-20` | 20px | 面板/对话框主标题（少用） | 1.25 |
| `fs-16` | 16px | 分区标题 / 强调数值 | 1.35 |
| `fs-14` | 14px | 正文 / 按钮 / 输入 | 1.5 |
| `fs-13` | 13px | 界面默认（树 / 属性 / 菜单） | 1.45 |
| `fs-12` | 12px | 次要标签 / 状态栏 / 表头 | 1.4 |

规则：梯度比例 1.125–1.2，元素多、对比小即可；等宽只用于数字/编码/日志，不用于中文正文。

## 3. 间距与圆角（Spacing & Radius）

**间距**基准 4px：`--space-1..8` = 4 / 8 / 12 / 16 / 24 / 32。

- 机架（顶栏、工具条、页签）用紧凑档：`8 / 12`
- 面板内边距：`12–16`
- 分区之间：`16–24`
- 列表行内边距：纵 `6–8`、横 `10–12`（行高 28–32）
- 表单控件间距：`8–12`

**圆角**：`sm 4` / `md 6` / `lg 10` / `pill 999`。

- 输入框 / 小控件：`4`
- 按钮 / 卡片 / 面板容器：`6`
- 浮层 / 大卡 / 画布工具浮岛：`10`
- 标签 / 圆形图标按钮：`pill`
- ⛔ 卡片圆角 **不超过 16px**（过圆是 AI 味）。

## 4. Elevation / 阴影

明度分层是主要手段，阴影只在「真正浮起」时加。

| Token | 深色 | 浅色 | 用途 |
|---|---|---|---|
| `shadow-sm` | `0 1px 2px hsl(220 40% 2%/.40)` | `0 1px 2px hsl(214 30% 40%/.12)` | 按钮 / 输入聚焦 |
| `shadow-md` | `0 4px 12px hsl(220 40% 2%/.45)` | `0 6px 16px hsl(214 30% 40%/.15)` | 下拉 / 画布工具浮岛 |
| `shadow-lg` | `0 12px 32px hsl(220 40% 2%/.55)` | `0 16px 40px hsl(214 30% 40%/.18)` | 弹窗 / 命令面板 |

⛔ 禁止「1px 边框 + ≥16px 大模糊阴影」同时出现在同一元素（ghost-card 反模式）：二选一。

---

## 5. 动效（Motion）

- 时长：`fast 150ms`（hover/焦点）、`base 200ms`（展开/切换）、`slow 250ms`（面板/抽屉）。
- 缓动：`--ease-out: cubic-bezier(0.22, 1, 0.36, 1)`（指数式 ease-out，无 bounce / 无 elastic）。
- 动效**只传达状态**（状态变化、反馈、加载、展开），不做入场编舞。
- 列表可做 stagger；不给整页统一入场反射。
- **必须**提供 `@media (prefers-reduced-motion: reduce)` 降级（改为瞬切 / 淡入）。

- 状态栏 `28px`，`fs-12`，`ink-secondary`；同步点用 `success`/`warning`/`danger`。

## 8. 图标（Icons）

- 统一线性图标，`1.5px` 描边，`16 / 20px` 两档；同一界面不混线性/面性。
- 树节点类型图标可着语义色区分（管道/设备/结构/电气/仪表），但保持低饱和，不与强调蓝抢。

---

## 9. 可访问性（Accessibility）

- 正文对比 ≥ **4.5:1**，大字（≥18px 或粗体≥14px）≥ **3:1**。
- 已核验（深色）：`ink` on `bg` ≈ 15:1（AAA）；`ink-secondary` on `panel` ≈ 6.5:1（AA）。
- `ink-muted` 仅用于**非必要**信息（占位符/禁用/时间戳），不承载正文。
- 焦点必须可见：键盘焦点一律 `ring` 环，不移除 outline。
- 颜色不单独承载信息：日志级别、校审结论除色点外附文字/图标。

---

## 10. 反模式清单（Bans）

- ⛔ 装饰性侧边色条（>1px 且无状态含义）。选中态状态条属例外（见 6.6）。
- ⛔ 渐变文字（`background-clip:text`）。强调靠字重/字号。
- ⛔ 默认毛玻璃（glassmorphism）。浮层用实底。
- ⛔ 卡片圆角 > 16px。
- ⛔ `1px 边框 + ≥16px 阴影` 同框。
- ⛔ 装饰性动效 / 整页入场编舞。
- ⛔ 同一操作在不同位置长得不一样（组件词汇必须一致）。
- ⛔ 为「新奇」自造标准控件（滚动条 / 表单 / 模态）。

## 11. 落地映射（gpui-component）

本规范的每个 token 已在 `src/gui/theme_engineering_console.rs` 落为 `ThemeColor` 字段：`background/foreground/border/input`、`primary*`、`accent*`、`sidebar*`、`tab*`、`list*`、`table*`、`success/warning/danger/info*`、`description_list_label*` 等。切换主题：`theme_engineering_console::apply(cx, /*dark=*/ true|false)`。网页/其他端用 `assets/design-tokens/engineering-console.css`（默认深色，容器加 `.theme-light` 切浅色）。
