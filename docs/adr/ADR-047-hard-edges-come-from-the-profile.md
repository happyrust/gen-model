# ADR-047：硬边由轮廓给，不由夹角猜

状态：Proposed（2026-08-24）

关联：ADR-030（分阶段退役 OCC 三角化）；ADR-029（布尔走 manifold-csg——法向在布尔之后
被重算的那一步就在它那里）；ADR-044（曲面段数按真实半径算，本 ADR 与它同一个病根：
拿「差不多」的数顶替反编译出来的规则）。
逆向全文：`plant-4/libgm-boolean-algorithm.md` §7.9.2 第 4 条；
证据 `docs/evidence/2026-08-24-ida-gm-collar-ruled-solid.md` §六。
术语见 `CONTEXT.md`。

## 背景

`d0088e93 fix(geom): smooth curved-surface normals` 修的是一个真问题：manifold 交回来的
网格没有法向，逐三角写面法向的话穹顶会渲染成多面体。它的修法是**几何启发式**——
同一位置上夹角在 **10°** 以内的面按面积加权平均，超过就各写各的
（`src/fast_model/manifold_csg.rs` 的 `SMOOTH_NORMAL_COS = cos(10°)`）。

10° 是猜的。E3D 不猜：

- `GM_Profile::getPolygonForFacet`（3.1 libgm `0x1008F8B0`）的第二个出参逐顶点记
  「有几条 span 在这里收尾」，**相邻两段不平滑相接时把该项取负**；闭合处（末段接回
  首段）另判一次，不平滑就把末点与首点**一起**取负。
- 判据是 `D2_Span::leadsSmoothlyTo`（3.1 **libgeom** `0x10029B50`）：
  `|1 − dot(lastTangent(a), firstTangent(b))| ≤ 1e-6`，换成夹角约 **0.081°**。

两者的分歧不是精度差异，是**判据类型**不同：

| 情形 | E3D | 10° 阈值 |
|---|---|---|
| 一段弧被离散成 8 段（相邻面片夹角 45°） | 光顺——弧内部没有硬边 | 判成硬边，圆柱渲染成八棱柱 |
| 两条直边拐 5.7° | 硬边——切线不连续 | 判成光顺，折痕被抹平 |
| 两段相切的弧（倒角接直边） | 光顺 | 光顺（碰巧一致） |

也就是说：**面片有多粗和形状有多折是两回事，用一个角度阈值同时回答这两个问题，
两头都会答错**，而且错的方向随离散密度漂移——段数一改（ADR-044 / T056 正在改），
同一个构件的着色就会变。

本仓另有一处更朴素的做法：`sweep_mesh` 的侧壁一直是**逐四边形独立顶点、写面法向**，
即「全是硬边」。弧墙、斜切墙、异型截面的曲面部分因此一律渲染成折面。

## 决策

1. **硬边的权威是轮廓，不是夹角。** 哪个顶点是硬边由
   `libgm_discretise::spans_meet_smoothly` 判定（`leadsSmoothlyTo` 的 1e-6 点积口径），
   在截面离散时就逐点算出来并随环一起传下去。生产路径上不得再用夹角阈值决定
   「这两片要不要共享法向」。

2. **这个 1e-6 不许与另外两个相切判据互相顶替。** libgm 里三个判据各有各的用途：
   `leadsSmoothlyTo` 的 1e-6（轮廓硬边，本 ADR）、`isTangentDiscontinuity` 的固定
   22.5°（布尔交线边定型，§6.8.3）、`isSharp` 的 ≈48.3°（归一化折角，§6.6）。
   谁也不是谁的近似，共用一个常量就是三处同时错。

3. **沿扫掠方向没有硬边。** 回转 / 放样面沿扫掠方向是同一张连续曲面，硬边全是沿扫掠
   方向跑的那些棱。端盖与侧壁的接缝永远是硬的。

4. **法向分组不改拓扑。** 顶点仍逐面片独立，只是同一位置的角点在软边处拿同一个法向。
   水密性、绕向、体积、`.mesh` 的顶点数都不因着色而变——着色出了问题不该连带成
   几何问题。

5. **布尔之后的那一段单独排期，在它接上之前 `SMOOTH_NORMAL_COS` 保留。**
   manifold 交回来的三角汤没有轮廓出处，要把硬边带过布尔得走它的属性通道
   （见「后果」）。在那之前 10° 仍然是布尔结果唯一的分组依据——但它是**已知的近似**，
   不再是「就这么定的规则」，删除它的条件写在 spec 028 的 Phase 3。

## 后果

- 弧墙 / 斜切墙 / 环形截面的侧壁从逐片平直变成光顺，同一构件的 `.mesh` 顶点位置一位
  不变、法向变。渲染上是肉眼可见的差别，发布说明要点名。
- 段数改动（ADR-044 / T056）不再顺带改变着色：段数只影响面片密度，硬边位置由轮廓定。
- 布尔前后的着色口径暂时**不一致**：未参与布尔的构件走轮廓硬边，参与布尔的走 10°。
  这是本 ADR 明确接受的过渡态，不是遗漏；Phase 2 接通属性通道后收敛。
- 极小非零 bulge（`0 < |bulge| < 3.06e-5`）在 libgeom 的切线函数里落进一条**非单位**的
  退化分支，实际效果是「必被判成硬边」。本仓 `profile_spans` 会先把这种 bulge 收成
  尖角，所以那条分支不可达；照抄时不要顺手归一化，否则行为会变。

## 否决方案

- **把 10° 调小 / 调大。** 调小则粗弧变多面体，调大则浅折角被抹平。这两个方向是矛盾的，
  单个阈值不存在能同时对的取值——问题不在阈值大小，在判据类型。
- **按离散密度动态算阈值（例如取 `2π/n` 的一半）。** 等于用面片密度去推形状，
  在混合密度的截面（倒角弧与大弧同环）上依然会错，而且段数一改着色就飘。
- **顶点合并 + 一次性平均全部相邻面。** 那是「全部软」，折角全没了，与现状「全部硬」
  一样是把判据丢掉。
- **等布尔那条路一起做。** 布尔那一段要动 manifold 的属性通道，工作量与风险都高一档；
  而未参与布尔的构件（弧墙 / 斜切墙是大头）现在就是**全硬**的最差状态，没有理由陪着等。
