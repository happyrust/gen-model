# ADR-041：8000 初始化的 CATA 生成只做落盘后页内提速

## 状态

已接受（2026-08-24）。引用 ADR-001、ADR-011、ADR-017、ADR-021、ADR-025。

## 背景

空 RocksDB 的 8000 初始化显示，dabacon 数据落盘后，BRAN/HANG 的 CATA 模型阶段仍按
实例重复读取子节点、属性、目录引用和世界变换；真实 `gen_cata_geos` 没有进入统一几何
并发边界。逐根查询与重复解析成为模型阶段的主要耗时，而不是 RocksDB 落盘或 OCC。

## 决策

1. 初始化协议保持“解析后直接落盘 RocksDB，再生成模型”。本阶段不改变解析、水位、
   暂存窗口或 baseline 发布协议，也不引入 Legacy 或内存数据库路径。
2. 每个现有分页建立只读预取快照。批量 API 保持输入 `RefnoEnum` 身份；记录缺失为
   `None`，查询、连接或解码失败为 `Err`。快照不得跨页或跨重建复用。
3. 分页内按唯一 `cata_hash` 解析一次。CATA 与 Manifold 进入同一个进程级
   `geometry_permits` 闸；任务只产生本地结果，完成后按 CATA 身份和实例参考号稳定合并。
4. 单件数据缺陷写入 `geom_error` 后继续同页；整批预取、连接或事务失败使分页失败，
   由原有持久任务重试，禁止部分成功回执。
5. `geometry_permits=1` 是运行时串行回滚档。配置只接受 1..=64；缺省取可用并行度并
   受同一上限约束，不允许第二个 Semaphore 或写死 4/16 路并发。
6. 性能完成边界由调度根的成功集合与 `geom_error` 集合覆盖、生成阶段终态和日志摘要
   共同裁决；轮询表瞬时 `pending=0` 不是计时或完成前提。
7. 后续跨页复用遵循 ADR-045：只缓存 committed `Arc<ScomInfo>`；ADR-017 `kv-mem`、
   `CataContext`、设计属性和变换仍严格限定于暂存窗口或当前页。

## 后果

- 数据库格式、模型身份、HTTP/Python 响应与分页根数量均不变。
- 数据库级故障保持可重试；坏模型不会拖住同页其它模型，也不会静默消失。
- 第一阶段批量读取可独立保留；若并发等价或资源门失败，只需把额度设为 1。
