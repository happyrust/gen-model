# 文件监控排除规则说明

## 概述

增量更新系统现在支持文件排除功能，可以自动过滤掉不需要监控的文件类型，避免对系统文件、临时文件、可执行文件等进行不必要的处理。

## 排除规则

### 1. 文件扩展名排除

以下扩展名的文件会被自动排除：

#### 可执行文件
- `.com` - COM可执行文件
- `.exe` - Windows可执行文件
- `.dll` - 动态链接库
- `.sys` - 系统文件

#### 临时文件
- `.tmp` - 临时文件
- `.temp` - 临时文件
- `.bak` - 备份文件
- `.backup` - 备份文件
- `.old` - 旧文件
- `.cache` - 缓存文件

#### 系统文件
- `.lock` - 锁文件
- `.pid` - 进程ID文件
- `.log` - 日志文件

#### 编辑器文件
- `.swp` - Vim交换文件
- `.swo` - Vim交换文件
- `.~` - 临时备份文件

### 2. 系统文件名排除

以下特定文件名会被排除：

- `thumbs.db` - Windows缩略图缓存
- `desktop.ini` - Windows桌面配置
- `.ds_store` - macOS文件夹配置

### 3. 临时文件模式排除

- 以 `~$` 开头的文件（如Office临时文件）

### 4. 隐藏文件排除

- 以 `.` 开头且长度大于1的文件（Unix风格隐藏文件）

## 工作原理

### 多层过滤机制

1. **事件预过滤**: 在文件变化事件处理的最开始就过滤掉不需要的文件
2. **初始化过滤**: 在系统启动时扫描文件时也会应用相同的过滤规则
3. **实时监控过滤**: 在实时文件监控过程中持续应用过滤规则

### 过滤流程

```
文件变化事件 → 预过滤检查 → 如果被排除 → 跳过处理
                ↓
            如果通过 → 继续正常处理流程
```

## 日志输出

当文件被排除时，系统会输出相应的日志信息：

- `排除文件（扩展名）: "文件路径"` - 因扩展名被排除
- `排除文件（系统文件）: "文件路径"` - 因系统文件名被排除  
- `排除文件（临时文件）: "文件路径"` - 因临时文件模式被排除
- `排除文件（隐藏文件）: "文件路径"` - 因隐藏文件规则被排除
- `所有变化的文件都被排除规则过滤，跳过处理` - 当事件中所有文件都被排除时

## 示例

### 被排除的文件示例

```
test.com          → 排除文件（扩展名）
program.exe       → 排除文件（扩展名）
library.dll       → 排除文件（扩展名）
temp.tmp          → 排除文件（扩展名）
backup.bak        → 排除文件（扩展名）
debug.log         → 排除文件（扩展名）
thumbs.db         → 排除文件（系统文件）
desktop.ini       → 排除文件（系统文件）
~$document.docx   → 排除文件（临时文件）
.hidden           → 排除文件（隐藏文件）
.gitignore        → 排除文件（隐藏文件）
```

### 不被排除的文件示例

```
data.db           → 正常处理
config.txt        → 正常处理
ams7334_0001      → 正常处理（PDMS数据库文件）
zdj7015_0001      → 正常处理（PDMS数据库文件）
document.pdf      → 正常处理
```

## 性能优化

### 早期过滤

- 在文件事件处理的最早阶段就进行过滤，避免不必要的文件扫描和处理
- 减少系统资源消耗，提高监控效率

### 批量过滤

- 对事件中的多个文件路径进行批量过滤
- 如果所有文件都被排除，直接跳过整个事件的处理

## 配置说明

当前的排除规则是硬编码在 `should_exclude_file` 方法中的。如果需要修改排除规则，可以：

1. 修改 `excluded_extensions` 数组来添加或删除文件扩展名
2. 修改 `excluded_patterns` 数组来添加或删除特定文件名模式
3. 调整隐藏文件的判断逻辑

## 测试验证

系统包含了完整的单元测试来验证文件排除功能：

- 测试各种应该被排除的文件扩展名
- 测试系统文件名排除
- 测试隐藏文件排除
- 测试不应该被排除的正常文件
- 测试大小写不敏感的处理

## 注意事项

1. **大小写不敏感**: 文件扩展名和文件名的比较都是大小写不敏感的
2. **性能影响**: 文件排除功能对系统性能的影响很小，因为是在早期阶段进行过滤
3. **日志记录**: 所有被排除的文件都会在日志中记录，便于调试和监控
4. **向后兼容**: 该功能不会影响现有的文件处理逻辑，只是在处理前增加了过滤步骤

## 未来扩展

可以考虑的功能扩展：

1. **配置文件支持**: 将排除规则移到配置文件中，支持动态修改
2. **正则表达式支持**: 支持更复杂的文件名匹配模式
3. **目录排除**: 支持排除整个目录
4. **白名单机制**: 支持强制包含某些文件，即使它们匹配排除规则
