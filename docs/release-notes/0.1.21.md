面向使用者的更新摘要（后端 gen-model 0.1.21）：

- **默认开箱使用 kv-mem**：未配置 `store_mode` 或使用发布包出厂模板时，服务自行用包内 SurrealDB 在 `127.0.0.1:8009` 拉起内存库；无需预装或手工启动数据库。内存数据随进程退出消失，数据面采用 read-through。
- **一键创建本机持久库**：需要跨重启保留摄入数据时，配置向导第②步可选「新建本机持久库」——服务在默认 `127.0.0.1:8010` 自动拉起**落盘**库，数据在 `workspace\.surreal\<项目代号>`。配置里写 `store_mode = "spawned-rocksdb"` 与向导等效。
- **绑定地址可选局域网**：`v_ip` 填 `0.0.0.0` 可让局域网其他机器连这台库；向导会提醒——库的凭据默认 root/root，**暴露前先改 `v_user` / `v_password`**。
- **换项目代号 = 新库**：持久库目录按项目代号分家；换代号后旧目录留在盘上（不是丢数据），不用了人工删。
- **配置更难写坏**：自带存储两档（新建持久库 / 默认 kv-mem）地址留空时——向导自动补默认；直接手改配置文件留空的，启动会进配置向导而不是报一个难懂的绑定错误；网页写口则直接拒绝这种必坏组合。
- **后端与 plant-ui 一体化发布**：`ams-local-0.1.21-full.zip` 内含后端、Web、运行资源和配套 SurrealDB；解压后双击 `Start-AMS.cmd`，首次进入配置向导。
- **发布自检加一腿**：出包冒烟从两腿变三腿，新腿专考「自带持久库」（起到正常服务、库目录真落盘）。
- 顺带修复：包内 `Start-Surreal.ps1` 兼容旧模板的 `v_port="0"` 哨兵并回落 8010；向导第②步的单选项整块可点（原来要精确点中小圆圈）。
- 已知边界：持久库目录不自动瘦身，磁盘占用随库规模增长；默认 kv-mem 重启即清空。
