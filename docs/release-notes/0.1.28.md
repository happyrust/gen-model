# 0.1.28

- **房间归属改在生成网格那一刻算，边随根的回执一起落库（ADR-073 D1 / D12）。** 此前要等 flush 回读磁盘上的 `.mesh` 再判一遍，同一根几何被读两次、两条路还可能给出不同答案。现在生成 worker 拿手上就要写盘的网格取判定点，房间边挂在根回执上走完整条发布链，flush 只负责渲染；回执带的边代号与构件集对得上就不再现算，对不上才兜底。一个 dbnum 任务开工前冻一台房间计算器，整个任务从头到尾用它，`model_room_generation` 盖的是这台计算器的代号、不是收尾那一刻的常驻代号。
- **面板变了不再整库重算房间边，改成拿面板的新旧包围盒反查受影响的根（ADR-073 D13）。** PANE 动几何、FRMW / SBFR 改名、CWALL / CFLOOR 搬迁之后，此前唯一的填法是把本库全部根的几何回读一遍重判；现在只重算与那块面板新旧盒相交的几根，整库重算降为兜底（空间树不可用、有根折不出来、覆盖面对不上就退回去）。命中落在别的库的，连同这一段换代停进那个库的进程内槽，由它的下一个任务沿准入链消费——不再让第二个库整库重算一次。停放槽重启即丢，丢了是多算不漏算。
- **房间的点包含判据换成三方向射线奇偶，修掉一批「房间外的构件被判成房间成员」（ADR-010 §3）。** 旧判据用 parry 的 `contains_point`，它在房间棱柱盖面的**零面积三角**上会把盒外的点判成内部；房间盖面是两百多个船体型线点的三角剖分，共线处天然就有这种碎片，而哪些碎片经浮点变换后恰好零面积会变，于是同一份几何两次运行能给出不同的边集。现在面板三角网有唯一口径（0.01 mm 焊接、剔掉退化三角），判定走三条歪斜射线数穿越、三取二。实测 ams 1112 边数 6161 → 5858、8000 4379 → 4284，**全是减少、没有一对新增**，冷重启后重算逐字相同。
  - **升级要做的事**：`inside_count` 的数值口径跟着变了（旧值含误计）；**存量 `room_relate` 不会自己重算**，每个 DESI 库要发一次 `POST /api/v1/dbnums/{dbnum}/model/rebuild`。「横穿凹形房间的长管八角全在外」那条已知盲区本版照旧。
- **新增 `GET /api/v1/spatial/surface-clearance`：一对构件之间按真实外表面量净距。** 给一根管和一面墙，用两侧真实三角网算最近距离与两侧最近点；命中墙主面时再沿命中三角的法向打一条垂距射线，量出「垂直穿过这面墙要走多远」。洞壁单独分类成 `opening`（沿自身法向严格在墙的包围盒内部、且往前还能撞回本墙才算），共棱处选法向贴合来向的那个面，垂距结果多一格 `method` 说明它是怎么得到的（`ray` 射线 / `contact` 贴合 / `edge` 棱上）。两侧贴合（距离已在容差内）时不再打射线，垂距就是距离本身、0 mm 就报 0。
- **新增 `GET /api/v1/spatial/centerline` 与 `GET /api/v1/spatial/nearest-clearance`；`nearby` / `nearby/refnos` 加 `source_mode=bran_centerline`。** `centerline` 把一条 BRAN 的中心线按段给出来（成员的到达→离开点加隐式管身，每段带 noun / 是否隐式 / 外径）。管-管间距因此改按「两条 BRAN 平行直段的中心距」算，不再拿包围盒近似。
- **新增 `POST /api/v1/element/ptset` 与 `POST /api/v1/element/plines`。** 前者直读构件目录的 P 点集，后者给出型材的 PLINE 线端点，并带 `snap_points`（SCTN 名下 FITT / SJOI / SUBJ / SNOD 的沿轴位置，对应 E3D Pick Settings 里 Significant Snap Points 那三档分段）。测量与拾取不必再各自复述一遍目录几何。
- **隐式管身（头段 / 尾段 / 中间段）两条几何修复。** ① 支管重新发布时，管身的包围盒与世界变换此前会被第一次发布的值钉住：端点换了、几何不重算，画出来的还是旧位置。现在分支重置连盒带变换一起删，本轮要插的管身按身份先删一遍再插。② **属主 ZONE / PIPE 带摆放（旋转或平移）的支管，头段管与尾段管此前整条不发布、也不报错**——容器两端读的是文件里的属主相对坐标，而构件那一端已经折算到世界坐标，一条槽位两个坐标系，算出来的方向反了就被默默丢弃。现在容器两端同样折过属主链。
- **元数据门第二档的开关 `model_skip_unread_attribute_changes` 退役。** 它早已是空挡：判据本身就是「字典 DCHC=0 且生成侧没有一处按名字读它」，没有独立旋钮，而配置里设成 `false` 的字面意思与实际行为恰好相反。行为逐位不变；`DbOption.toml` 或环境变量 `AIOS_MODEL_SKIP_UNREAD_ATTRIBUTE_CHANGES` 里还留着它的部署，启动时会打一条告警提醒删掉，不影响运行。
- **只动摆放就不重建几何的判定补了三条排除。** P23 类、几何由属主消费的锚点（负体 / 开孔 / 剖面 / 几何集）、以及 EVALAT 规则 M 涉及的元素，这三类在 E3D 里本来就是「位姿一变整件重建」，此前会被当成刚体平移放过去。`CACHID` 改为单列一枚戳，不再混进「属性变了没有」的比较集。
- **校审三处修复。** ① 驳回后带着未关闭批注的任务不得重新提交，`active` 与 `agree@sj` 走同一道批注闸门；② 工作流事务遇到数据库写冲突按 SurrealDB 的口径重试，不再把真正的失败原因吞成「未返回确认记录」；③ 批注截图作为正式附件类型放行给当班审核人。
