# 0.1.32

- **`gen-model-refactor` 已正式合入 model-cache 线。** 本版从合并提交 `402ff3582` 之后的 `gen-model-refactor` 构建，完整包含 0.1.31 的增量模型缓存、房间归属、版本接口和内存控制能力。
- **交付删除台账可在 refactor 线直接使用。** `datacenter_delete` 会在最小交付单元被删除或自身 `NAME` 变化时保留删除前位号、参考号、最近 ZONE、会话、时间与原因；下属管件不误记，重放按 `[refno, old_name]` 幂等收敛。只读接口仍为 `GET /api/v1/datacenter/deletes`，gen-model 只维护台账，不负责向中台提交或清表。
- **结构模型几何继续向 E3D TTY / RVM 收敛。** GENSEC 两端按 SPINE `DRNS` / `DRNE` 斜切，圆弧墙 JLDATU 越界按端切向外推；JLDATU / PLDATU、SCTN / STWALL 下 FITT、JOIS / JOIE 关节模板负体以及 datum 树 FIXING 的扣负体均已补齐。
- **APS250110 对拍覆盖提升。** 结构模型与 E3D RVM 对上的根由 574 逐步提升到 1179 / 2995；新增读取集合包含 `HPREF`、`NAPP` 与 `NGMR`，用于上述标架和负体语义。
- **升级说明。** 数据结构不需要迁移；从 0.1.31 升级可直接替换程序。`datacenter_delete` 是持久交付台账，不随模型库重建或清库而删除。
