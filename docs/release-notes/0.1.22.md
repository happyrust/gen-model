# 0.1.22

- `aios-database.exe` 现在同时携带发布版本、唯一构建 ID、Git 提交和 Windows
  `FileVersion` / `ProductVersion`；`version --json`、`/api/v1/health` 与发布清单都可查询。
- 新增 `scripts/New-AiosDatabasePatch.ps1`：从上一版与新版 EXE 生成一个可直接运行的
  自包含增量 patch EXE。
- patch 应用前后均校验大小与 SHA-256，以同目录临时文件生成新版，最后才原子替换；
  旧 EXE 保留为 `.bak-<hash>`，源版本不匹配或服务仍在运行时不会修改安装文件。
- 每份 patch 生成后会在隔离目录自动验证 dry-run、无参数直接应用、目标/备份哈希，
  再验证第二次应用返回 `already-current` 且不重复生成备份。
- MDB 名配置错误时，启动日志会列出 SYS 库中全部 MDB 候选名称。
- runtime 发布档默认改用 `embedded-mem`：无 SurrealDB 子进程和数据库端口冲突；
  浏览器的树、属性、搜索、模型和网格统一走当前页面同源 API。包内仍保留
  `bin\surreal.exe`，需要外部 SQL / 探针时可切回 spawned-mem。
- 新增 `http_public_addr`：`http_api_addr` 只负责 socket 监听，前者只负责日志、
  自动打开与分享链接。推荐 `http_api_addr="0.0.0.0:9099"` 配合
  `http_public_addr="<本机局域网IP>:9099"`，本机配置入口仍通过回环地址访问。
- 配置向导可选择并保存 embedded-mem，并独立编辑监听地址与对外展示地址。
- runtime 冒烟会验证 setup 模式、embedded 正常模式和“没有 Surreal 子进程”；
  房间兼容直连页在 embedded 下明确提示切换 spawned 档，不会误连旧 TCP 端口。
