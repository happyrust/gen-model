# 0.1.33

- **`datacenter_delete` 改为 refno 单键事件表。** ID 现在只使用参考号值，例如 `datacenter_delete:24383_66459`，不再包含 `pe` 记录链接或 `name`；写入改为 `INSERT IGNORE`，同一参考号只保留首次删除或改名事件，重放和后续同参考号事件不会覆盖原字段或增加行。
- **只记录已发布到数据中台的参考号。** 生成事件前会按同一参考号 ID 批量查询 `datacenter_version`；对应记录不存在时不写事件。判断只看记录是否存在，不按 `version`、`status` 或 `review_status` 过滤，也不把这些字段复制到事件表。
- **事件字段与职责保持收敛。** `refno`、首次事件的老 `name`、`type`、`zone_refno`、会话与原因继续作为普通字段保存；gen-model 只维护事件表，不提交、不确认、不清理事件，后续处理交给第三方，rs-server 本版未修改。
- **验证。** Rust 定向测试、SurrealDB 2.1.4 兼容测试均通过；真实 E3D TTY 夹具 10/10 通过，验证首次改名写一行、恢复改名因同 refno 被忽略、交付单元删除写一行，其余场景不误记。
- **升级注意。** 0.1.32 及更早版本已经写入的数组 ID 行不会自动转换为 refno 单键。若现场已有 `datacenter_delete` 数据，应在升级前由事件消费方完成处理，或按业务需要迁移/清理旧行；本服务不会擅自删除事件记录。
