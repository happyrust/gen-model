# 2026-08-24 IDA：边类型与平滑组——E3D 到底在哪儿用夹角

`docs/evidence/2026-08-24-ida-gm-collar-ruled-solid.md` §六 钉下了**轮廓**上的硬边判据
（`leadsSmoothlyTo`，1e-6 点积）。这一轮回答它留下的那个问题：**布尔交线上的边算硬
还是算软**——那是 ADR-047 / specs/028 Phase 2 的前提，而我在 plan 里写的猜测
「交线是硬边应当自然落出来、不需要额外规则」**只对了一半**。

方法：长驻 idalib `idalib-18608`（libgm 3.1），只读查询，未写 idb。

## 一、平滑组怎么分：走到「可见」边就停

`AM_CoEdge::calcStartNormal`（2.10 `0x1000c390` / 3.1 `0x1001e100`，teach 0011 §8.1）：
绕顶点走相邻面，**撞到 `edge->isVisible()` 的边就停**，把这一组的面法向求和归一，
写回组内每条 co-edge。顶点法向因此只在「由不可见边连通」的面之间平均。

`GM_Edge::isVisible`（3.1 `0x10004a60`）3.1 版逐字复核，与 2.10 记录一致：

```c
bool isVisible()     { return type != 1 && type != 5 && type != 6; }
bool isCurve()       { return type == 4; }
bool isSurfaceEdge() { return type != 0 && type != 4; }
```

`GM_EdgeType`（teach 0011 §6.4）：`1 Invisible` = 平滑，`2 Visible` = 硬，
`3 Set-op intersection`，`5/6` 是消隐阶段的不可见标记。**所以「硬边」在 libgm 里
不是一个几何量，是边上的一个枚举值**；谁写这个值，谁就是权威。

写它的有三处，各有各的规矩：

| 边从哪来 | 类型谁定 | 判据 |
|---|---|---|
| 图元建面时 | 图元自己在 `calcFacets` 里写死（teach §8.2） | 箱/棱锥全 2；柱端圈 2、竖缝 1；球 / 碟 / 环面全 1 |
| 轮廓扫出来的侧壁 | `getPolygonForFacet` 第二出参的负号 | `leadsSmoothlyTo`：`|1 − 点积| ≤ 1e-6`（≈0.081°） |
| **布尔交线** | **`normaliseStage2` 事后定型** | **`isTangentDiscontinuity`（见下）** |

## 二、`GM_Facets::normaliseStage2`（3.1 `0x10066E70`）——交线边的定型

```text
skip = (tangTol <= 0.0)                     // tangTol 只是开关，不参与判据
for each edge e where e.type == 3:          // 布尔新建的交线边
    a = e.facet0 ; b = e.facet1
    if (a < 0 && b < 0):  gm_reportInternalFault("GM_Facets.cxx", 3636)
    else if (只有一侧有面):
        e.label = 那一侧的 label ;  e.type = 2          // 硬
    else:
        e.label = max(labelA, labelB)
        if (skip || isTangentDiscontinuity(a, b)):  e.type = 2   // 硬
        // 否则保持 3
收尾：所有仍为 3 的边 → type = 1                          // 软
```

**结论一句话：交线边默认是硬的，但 E3D 会明确地把「两侧相切」的那些改成软的。**

这直接推翻我在 plan 里写的那句「交线是硬边应当自然落出来，不需要额外规则」——
E3D 在这里**真的跑了一个几何判据**。少了这一步，相切的布尔缝（同轴等径圆柱相接、
倒角与母面相切）会留下一条亮缝。

另注：`tangTol`（`GM_User::tangtol_`，5°）在这里**不是阈值而是开关**——`≤ 0` 时
直接全部判硬。文档 §6.8.3 记的「不用 tangTol」是对的，但要连「它是开关」一起记，
否则下一个人会以为它没用。

## 三、`isTangentDiscontinuity`（3.1 `0x10066A40`）——判据本身

三个静态常量按字节读出（`read_u64` + `struct.unpack`）：

| 地址 | 值 | 是什么 |
|---|---|---|
| `0x101090D8` | `0.9238795325112867` | **cos 22.5°** |
| `0x101090E0` | `0.9999999999999999` | 1.0（≈ tan 45°），锥角比值门 |
| `0x101090E8` | `0.3826834323650898` | **sin 22.5°** |

阈值是**一次性算好缓存**的（`_Init_thread_header` 那一段）：

```text
t   = cos22.5²
c   = sqrt(t² + sin22.5²)          = 0.9354...
thr = 2·sin22.5 / c                = 0.8182115951456252
```

`thr` 是**两个单位法向之间的弦长**，换成夹角 **48.297°**。

> ⚠ **别把它记成「22.5° 判据」。** 22.5° 是生成常量，有效判据是法向夹角 **48.3°**——
> 差了一倍。文档 §6.8.3 写的「固定 22.5°」指的是那两个常量，照着 22.5° 实现会把
> 一大批本该判软的缝判成硬缝。同一族常量也出现在 `isSharp`（§6.6，同样是 0.8182 /
> ≈48.3°），两处是同一把尺子。

主体：

```text
chord = |n_b − n_a|                       // 两面单位法向之差
if chord > thr + 0.001:  return 1         // 硬：折得太狠
if chord < 0.001:        return 0         // 软：本来就共面
// 中间带：默认判硬，除非能找到「曲面还在往下弯」的旁证
建局部系：由 (n_a + n_b) 与 (n_b − n_a) 张成
for f in {a, b}:
    for 每条 type == 1（不可见/平滑）的边所连的邻面 g:
        把 n_g 映进该局部系
        若它落在锥内（|y|·1.0 + 0.001 > |x|）且 z 按 cos22.5 缩放后的模长
        不大于 chord − 0.001  →  return 0        // 软
return 1                                          // 硬
```

中间带那一段的几何含义：**这两面之间的法向跳变，是不是被邻面的法向「夹住」了**——
夹住就说明这是一张连续弯曲的曲面上的两片，不是折痕。**默认判硬，要有旁证才判软**，
方向与「宁可留折痕不可抹平」一致。

诚实标注：中间带这一段只读到上面这个程度，局部系的构造（`D3_Transform::map` 的六个
实参）与那个锥角门的精确几何含义没有逐位吃透；两个早退分支与常量是实证。

## 对 ADR-047 / specs/028 的修正

1. **决策 3「沿扫掠方向没有硬边」不受影响**，那说的是轮廓扫出来的侧壁。
2. **Phase 2 的假设要改**：交线不是「靠属性行天然分开」就完事——属性行确实会天然
   分开（那是硬的那一半），但 E3D 还会把相切的缝**主动合回软的**。照搬「交线一律硬」
   会在相切缝上留亮缝，正是 `d0088e93` 当初要治的那种毛病。
3. **10° 那个数的定位更清楚了**：E3D 在布尔缝上确实用几何判据，但用的是
   **48.3° 的法向弦长 + 邻面旁证**，不是 10°，也不是「同位置一律平均」。
   Phase 3 删 `SMOOTH_NORMAL_COS` 时，替换物不是「没有判据」，而是这一对：
   **边类型来自出处（图元 / 轮廓），交线边按 `isTangentDiscontinuity` 定型。**
